Página Web de Estética de Manos 💅

Este sitio web fue creado como proyecto de práctica con fines educativos en el desarrollo frontend. 
Está enfocado en el rubro de la estética de manos, ofreciendo una experiencia visual moderna y elegante inspirada en sitios profesionales como D-Uñas.

✨ Características principales:

✅ Estructura semántica en HTML con etiquetas como header, nav, main, section y footer.

✅ Formulario de contacto funcional integrado con Formspree para envío de mensajes.

✅ Diseño responsive con Flexbox y CSS Grid, adaptado a dispositivos móviles, tablets y desktop.

✅ Estilos personalizados en CSS con una paleta de colores bordó, elegante y femenina, utilizando tipografía Poppins desde Google Fonts.

✅ Contenido multimedia enriquecido con imágenes, íconos y video.

✅ Navegación interna fluida entre las secciones del sitio.

✅ Script modularizado en un archivo externo JavaScript (shop.js), que implementa fetch, localStorage, manipulación del DOM y funciones asincrónicas.

✅ Optimización básica de accesibilidad y SEO mediante etiquetas apropiadas, uso de alt en imágenes, etiquetas semánticas y estructura ordenada.

✅ Página de tienda (shop.html) totalmente funcional:
Muestra los productos de forma dinámica desde un archivo productos.json.
Permite agregar productos al carrito, editar cantidades, eliminar ítems y vaciar el carrito.
Cálculo automático de subtotal por producto y total general del carrito.
Persistencia de datos en el LocalStorage, incluso al recargar la página.
Contador de productos en tiempo real.
Mejora estética en la visualización de los ítems del carrito (precios, cantidades y subtotales organizados visualmente).

📦 Tecnologías utilizadas:

HTML5
CSS3 (Flexbox y Grid)
JavaScript (ES6+)
JSON para simulación de base de datos
Formspree para backend de formularios
